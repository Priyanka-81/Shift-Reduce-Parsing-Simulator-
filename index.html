Help & Shift-Reduce Principles

Core Concept

Shift-Reduce parsing is a bottom-up syntax analysis method. It uses a stack to hold grammar symbols and reads input tokens sequentially from left to right, reducing handles back up to the start symbol.

The Four Parsing Actions

  • SHIFT: Reads the next input token and pushes it onto the stack.
  • REDUCE: Replaces a matching RHS suffix on the stack with the LHS nonterminal according to an active grammar rule.
  • ACCEPT: Halts successfully when the stack contains only the start symbol above $ and input is exhausted ($).
  • ERROR: Occurs when no valid transition exists in the SLR(1) parsing table for the current state and lookahead token.

Simulator Controls

  • Run Complete: Evaluates the grammar and displays the full trace table instantly.
  • Step-by-Step: Initializes the parser and allows manual progression using the Next button.
  • Simulate Workflow: Automatically animates the parsing progression step-by-step with play/pause/stop controls.
  • Run Tests: Executes the 13 verification test cases to confirm parser correctness.

Notes on Grammar Format

Separate grammar symbols with spaces (e.g. E -> E + T | T). $ is reserved as the end marker. The browser frontend runs a verified client-side SLR(1) parser matching the Python terminal engine (shift_reduce.py).
